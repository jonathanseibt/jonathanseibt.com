# Cursor Guide

General Cursor truth. See @PROJECT.md (if any) for project-specific truth.

## Keeping docs current

**Always keep `PROJECT.md` (if any) and `README.md` up to date** in the same change as the things they describe.

Update **`CURSOR.md`** only when general Cursor/agent conventions change — not for project-specific details.

## Always-synced paths (“Don’t forget to keep”)

Treat every **`Don't forget to keep … in sync`** comment as a hard contract. Each such comment must explicitly name:

- the counterpart file(s), and
- the exact section(s)/entry block(s) that must stay aligned.

When changing synced entries (add/remove/rename), update all named counterparts in the same change.
