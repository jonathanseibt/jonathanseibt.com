# Jonathan Seibt

Monorepo for jonathanseibt.com

## Technologies

- Node.js 24.x
- [pnpm](https://pnpm.io) 10.34.x
- [TypeScript](https://www.typescriptlang.org) 6.0.x
- [Turborepo](https://turbo.build) 2.9.x
- [React](https://react.dev) 19.2.x
- [Next.js](https://nextjs.org) 16.2.x
- [Tailwind CSS](https://tailwindcss.com) 4.x

## Setup

```bash
pnpm install
cp apps/web/.env.example apps/web/.env
```

## Scripts

`pnpm dev`
